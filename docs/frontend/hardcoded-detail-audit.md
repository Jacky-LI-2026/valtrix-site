## 四、多语言支持要求

1. 所有硬编码内容都需要支持多语言
2. 使用V2版本的多语言组件
3. 中文内容默认启用，可以在后台修改
4. 所有非中文内容均是同步翻译中文内容
5. 翻译结果显示目标语言，不显示中文
6. 翻译的内容保持同样的内容排版

## 五、备注

1. 翻译问题暂时搁置，先解决硬编码内容的问题
2. 菜单多语言字段需要后续添加到数据库模型中
3. 部分页面已有API获取数据，但有硬编码的默认值，需要统一处理
4. 修改时需要保持前端页面的版式和设计不变
