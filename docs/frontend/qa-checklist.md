## 1. 链接（Link）闭环

| # | 检查项 | 通过标准 | 备注 |
|---|---|---|---|
| L1 | 顶部导航全部菜单项 | 每个链接点开为目标页面，**无 404 / 无 "Application error"** | 含下拉子菜单（产品中心/应用领域等，移动端重点） |
| L2 | 二级页进入方式 | ① 从导航点击进入；② 直接输入 URL；③ 手机/缩窄窗口点击进入 | 三种方式均须正常（曾出 Bug：仅"点击导航"触发 500） |
| L3 | 页脚链接 | 公司地址、备案、友情链接、社媒 | 新窗口/同页行为符合预期 |
| L4 | 详情页互链 | 产品→行业→服务→新闻→联系我们 闭环可回退 | 面包屑可返回上级 |
| L5 | 外部链接 | 后台填写的社媒/地图/文档下载等外链 | 目标可达，非法/失效 URL 有兜底 |
| L6 | 锚点与站内跳转 | 首页各 section 锚点（#products 等）正常定位 | 手机端不跳动错位 |
| L7 | 多语种切换链接 | 六语种（zh/en/ja/ko/fr/ar）切换后 URL 与内容一致 | 回退中文即异常 |

> 快速批量法：浏览器控制台抓所有 `<a>`，逐个 `fetch(url, {method:'HEAD'})` 或点击抽查；对「导航→二级页」用**缩窄窗口**重点回归（触发 RSC 导航）。

## 2. 文字（Text / Copy）闭环

| # | 检查项 | 通过标准 | 备注 |
|---|---|---|---|
| T1 | 六语种显示 | 每个语种下标题/正文/按钮/导航均为对应语言，**不出现中文夹杂** | 静态文案走 `config/i18n.ts`；内容走 API 多语言字段 |
| T2 | 首页区块 | Hero / 产品 / 行业 / 服务 / 关于 / 统计数字 | 数字单位、年份一致 |
| T3 | 详情页小节标题 | 岗位职责/应用场景/需要帮助？等 | 未字典化项已知（见已知问题） |
| T4 | 富文本内容 | 正文换行、列表、加粗、图片排版正常 | `dangerouslySetInnerHTML` 页重点看 |
| T5 | 无文案溢出 | 长标题/长描述在卡片内不溢出、不截断错位 | 缩窄窗口重点 |
| T6 | 表单/占位文字 | 联系表单、验证码弹窗、下载留资 | 提交/报错文案友好 |
| T7 | 500/404 兜底文案 | error.tsx / global-error.tsx / not-found 显示友好提示 | 六语种各看一次 |
| T8 | RTL 适配 | 阿拉伯语下整体 RTL、图标翻转 | |

| # | 检查项 | 桌面（≥1024） | 平板（768–1024） | 手机（≤480） |

## 6. 上线前快速回归脚本（建议每次执行）

```
1. 首页 / 6 个一级页 / 各 1 个二级详情页：SSR 直访全部 200
2. 缩窄窗口（≤480px）从导航点开全部二级页：无 500 / 无 Application error
3. iPhone 真机 Safari/Chrome/Edge/企业微信各点一遍导航 → 二级页
4. 切六语种：首页+1 详情页显示正常
5. 服务器日志：/root/.pm2/logs/zuowen-web-error.log 无新增 router state header / 前端兜底页崩溃
6. 后台：新增/编辑各 1 条内容（含传图），前台即时可见且图片为 WebP
```
