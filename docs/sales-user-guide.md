# 后台用户功能清单（销售角色）

> 适用范围：左文科技企业官网后台（8.130.65.182 / 本地 dev）。
> 本文档描述"销售用户"在后台拥有的全部能力、权限边界与配置方法。2026-09-07 起随"销售绑定产品 + 订单权限"功能生效。

---

## 1. 什么是销售用户

后台「用户管理」中的用户可被标记为 **销售**。销售与普通管理员/编辑的差异：

| 维度 | 销售用户 | 普通管理员 |
|------|----------|-----------|
| 登录后台 | ✅ | ✅ |
| 接待商城订单 | ✅（仅自己绑定产品产生的、且分配给自己或轮转到自己的订单） | ✅（全量） |
| 确认收到货款 | ✅（自己的订单） | ✅（全部） |
| 确认发货 / 输入物流单号 | ✅（自己的订单） | ✅（全部） |
| 手动指派销售 | ❌ | ✅ |
| 管理商品/内容/站点 | 仅按角色权限（默认无） | ✅（admin 角色） |

> 前台注册会员（Member）与后台用户（User）是两套独立体系，销售账号是后台体系。

## 2. 如何创建一个销售用户（管理员操作）

入口：**系统运维 → 用户权限**（UsersManager）

1. 点击「新增用户」，填写用户名 / 邮箱 / 密码 / 角色（可不选，销售不依赖角色）。
2. 打开 **销售跟进** 开关 → 出现两个配置项：
   - **轮转顺序**：数字小者优先接单（0、1、2…）。
   - **绑定销售产品**：勾选该销售负责的商城商品（多选）。**只有绑定了某产品，他才会收到该产品订单的分配与轮转。**
3. 保存。该用户即出现在订单「可分配销售」候选池中。

> 销售未绑定任何产品时：不会收到任何订单分配，订单将进入"待人工分配"，由管理员在订单详情手动指派。

## 3. 销售用户后台功能清单

入口：**能力市场 → 在线商城 → 商城订单管理**（或侧边栏「商城订单」）

### 3.1 订单接待（核心）

| 功能 | 说明 |
|------|------|
| 订单列表 | 顶部徽章显示"XX · 仅显示分配给我的订单"；非管理员销售**只能看到分配给自己的订单** |
| 待跟进筛选 | 一键筛选"已分配给我且 2 小时内未跟进"的订单（红色待跟进） |
| 订单详情 | 查看客户姓名/电话/邮箱/公司/地址、商品明细、规格、金额、支付凭证（截图）、支付方式 |
| 确认收到货款 | 客户付款后核对到账 → 点击「确认到账」，订单支付状态变为"已确认"，系统记录操作时间 |
| 确认发货 | 录入物流公司（顺丰 SF / 跨越 KY / 京东 JD）+ 物流单号 → 提交后订单变为"已发货"，系统记录发货时间，并向客户发状态通知邮件 |
| 标记已跟进 | 处理完客户沟通后点击「标记已跟进」，停止该订单的 2 小时轮转计时 |
| 订单状态流转 | 待确认 → 已确认 → 已完成 / 已取消（取消自动回补库存） |

### 3.2 跟进状态与轮转规则

- 新订单自动分配后，**2 小时**内未"跟进"（未处理订单/未标记），系统自动轮转给下一个绑定了同一产品、顺序靠后的销售，并邮件通知。
- 只有一名绑定销售时，超时会**再次提醒本人**并累计次数（不误转给别人）。
- 无任何销售绑定订单内产品时，订单**不自动分配**，通知中心提示"待人工分配"，由管理员手动指派。
- 超时时长可在 `site_config.shop_escalation_hours` 配置（默认 2 小时，测试可设 0.02≈72 秒）。

### 3.3 通知与邮件

- **站内通知**：后台右上角通知中心 →「商城订单」分类，聚合：新订单待跟进 / 跟进超时·已轮转 / 待人工分配。
- **邮件**：新订单分配邮件 → 负责销售邮箱；跟进超时转单邮件 → 下一销售邮箱（未配置 SMTP 时为开发模式，仅打印日志/回显，生产需在「系统设置 → SMTP 邮件」配置）。

## 4. 管理员专属能力（普通销售不可见）

| 功能 | 入口 | 说明 |
|------|------|------|
| 手动指派销售 | 订单详情 →「手动指派销售（管理员）」下拉 | 候选列表标注"已绑定本单产品 / 未绑定，谨慎指派"；指派后重置轮转计时 |
| 用户管理 | 系统运维 → 用户权限 | 销售开关 / 轮转顺序 / 绑定产品多选 |
| 全部订单视角 | 商城订单管理 | 管理员默认"全量视角"，可见所有订单并可操作 |

---

## 5. 权限边界（已实现并验证）

| 操作 | 销售（自己订单） | 销售（他人订单） | 管理员 |
|------|:---:|:---:|:---:|
| 查看订单列表 | ✅ 仅自己 | ❌ 不可见 | ✅ 全量 |
| 状态流转 / 确认到账 / 确认发货 | ✅ | ❌ 403「无权操作该订单」 | ✅ |
| 手动指派销售 | ❌ | ❌ 403「仅管理员可指派销售」 | ✅ |
| 查看可分配销售候选 | ❌ 403 | ❌ | ✅ |

## 6. 常见问题

**Q：销售勾了"销售跟进"但收不到订单？**
A：检查是否绑定了产品。绑定必须覆盖订单内商品（按商品 id 匹配），且销售状态为"启用"。

**Q：订单产品无人绑定会怎样？**
A：订单不自动分配 → 通知中心"待人工分配" + 兜底邮件发 info@ → 管理员在订单详情手动指派。

**Q：销售换了负责产品线？**
A：管理员在用户权限中重新勾选绑定产品即可；订单分配/轮转即时按新绑定生效（历史已分配的订单不追回）。

**Q：销售能看到价格/利润吗？**
A：能看订单金额与商品单价（与前台一致），无利润/成本字段。
