> 数据来源：`AGENTS.md`（逐日功能与验证记录）+ `docs/development-experience.md`。

## 八、可扩展功能建议（通用行业网站增值方向）

### A. 前台体验（高价值）
1. **在线客服/即时沟通**：微信/WhatsApp/在线聊天悬浮入口 —— B2B 询盘转化关键
2. **视频展示**：产品视频、工艺视频（设备类尤其适合），支持 B 站/YouTube 嵌入
3. **站内搜索增强**：全文检索 + 热门搜索词 + 搜索建议
4. **结构化数据 Schema.org**：Organization/Product/FAQ 标记，提升搜索引擎富摘要
5. **PWA 化**：离线访问 + 安装到桌面（移动端体验提升）

### B. 营销获客（中高价值）
6. **内容营销/博客**：行业知识库、技术文章（SEO 长尾流量）
7. **EDM 邮件订阅**：访客订阅 + 分组群发
8. **报价单/工单自动化**：表单触发自动生成报价请求/工单
9. **销售漏斗看板**：曝光→访客→留资→商机→成交 全链路归因

### C. 后台增强（中价值）
10. **区块可视化编排**：页面区块拖拽排序/显隐（当前固定结构）
11. **内容审核流**：草稿→审核→发布 多级流转
12. **多站点/多品牌**：同一后台管理多个子站（集团/多产品线）
13. **国际化深化**：货币/时区/计量单位本地化
14. **开放 API**：对外提供产品/新闻数据接口（供 App/小程序/第三方）

### D. 平台商业化（商业模式价值）
15. **SaaS 多租户**：客户自助开通、按授权 edition 分级功能
16. **升级回滚**：增量更新失败自动回滚 + 版本历史
17. **在线授权校验**：离线验签已足够安全，可加「心跳在线校验」可选
18. **客户工单/支持系统**：授权客户专属支持通道

## 九、结论（通用行业网站成熟度）

本项目已具备**通用行业企业官网的 90% 核心能力**，尤其在四方面达到产品级水准：

1. **多语言国际化** —— 六语种全栈 + 多通道翻译 + AI 通道，可作行业标杆
2. **内容管理完整性** —— 8 大模块 + 统一表单 + SEO/GEO 一键补全，CMS 能力完整
3. **商业化闭环** —— 商用授权 + 增量更新 + 定时备份 + 部署自动化，可复制交付
4. **营销获客链路** —— 留资审核制 + 商机管理 + 邮件通知 + 社交二维码，线索闭环已通

**下一阶段投入建议**（ROI 排序）：
- 短期（1 周内）：补齐待办 1/2（地图配置）、待办 6（标题字典化）、在线客服入口
- 中期（1 月）：站内搜索增强、视频展示、Schema.org、销售漏斗看板
- 长期（产品化）：模板切换引擎、SaaS 多租户、开放 API

> 数据/结论基于 `AGENTS.md` 逐日验证记录与生产实测，均为「已核验」事实。
