## 二、测试通过模块

### 1. 联系留言表单 (/contact) ✅
- 图形验证码 API 正常返回（captchaId + 算术题）
- 非法邮箱格式正确拦截（返回"请输入有效的邮箱地址"）
- 错误验证码正确拦截（返回"验证码错误，请重新输入"）
- 有效数据提交成功（返回留言 ID，数据入库）
- UI 表单字段可正常填充（姓名/公司/电话/邮箱/留言内容/验证码）
- 咨询类型下拉框正常加载

### 2. 询价车功能 ✅
- 询价车页面正常加载
- 从产品详情页可加入产品到询价车
- 询价车显示产品名称、型号、数量、小计
- 空表单提交显示"公司名称必填"校验
- 预估总价显示"面议"（价格隐藏模式）

### 3. 考察预约 (/visit-booking) ✅
- 页面正常加载，表单字段完整（姓名/电话/公司/邮箱/日期/时段/人数/备注）
- 提交成功后显示"预约提交成功"和预约编号（VT20260906-0002）
- API 提交正常，数据入库
- 必填校验：姓名和电话必填

### 4. 会员注册/登录 ✅ (API 层面)
- 注册页面正常加载
- 登录页面正常加载（邮箱+密码）
- API 注册正常（POST /api/public/member 返回 200，生成 member ID 和客户编号 ZW-000001）
- 注册成功后自动创建会员记录

### 5. 商城功能 (/shop) ✅
- 商品列表正常加载（11 个商品）
- 商品分类导航正常（半导体设备/金刚石材料/精密仪器/耗材配件）

- 购物车页面正常显示商品、价格、数量、优惠券输入、合计
- 购物车显示真实价格（¥2,800）

### 6. 价格显示模式 ✅

- /api/public/pricing-config 返回 mode=hidden

### 7. 产品详情页 ✅
- /products/growth/zw-10d 正常加载
- 产品图片轮播、技术规格、产品详情富文本正常渲染
