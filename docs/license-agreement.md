# 左文科技 企业官网系统 商用授权许可协议

> 版本：v1.0（2026-09-02）
> 本协议为通用模板，正式签约时由授权方按客户实际情况填写【占位】字段。

## 一、协议双方

- **授权方**：北京左文科技有限公司（以下简称"授权方"）
- **被授权方**：【客户公司全称】（以下简称"被授权方"）

## 二、授权内容

1. 授权方向被授权方授予**非独占、不可转让**的使用许可，允许被授权方在下列授权范围内使用"左文科技企业官网系统"（以下简称"本系统"）：
   - **绑定域名**：【域名列表 / 不限】
   - **授权站点数**：【站点数】
   - **授权版本**：【试用版 / 专业版 / 旗舰版】
2. 授权范围以授权方签发的**授权码**为准，被授权方在系统后台「授权管理」中激活。

## 三、授权期限

1. 授权有效期自激活之日起算，至【到期日期 / 永久】止。
2. 到期后需继续使用的，被授权方应联系授权方办理续期，续期以新授权码方式交付。

## 四、使用权限

被授权方有权：
1. 在授权码限定的域名与站点数范围内，部署、运行本系统；
2. 对本系统内的内容（产品、新闻、页面等）进行编辑、维护；
3. 按授权版本获得相应功能的使用权。

## 五、禁止事项

被授权方**不得**：
1. 将本系统或其授权码转让、转售、出租、出借、二次分发或提供给授权范围外的任何第三方；
2. 对本系统进行反向工程、反编译、破解、绕过授权验证，或移除、篡改版权及授权标识；
3. 将本系统用于授权范围之外的站点或用途；
4. 以本系统为基础开发同类型产品对外销售或提供服务。

## 六、维护与升级

1. 授权有效期内，授权方按约提供：
   - 系统升级包更新（在线更新或上传升级包）；
   - 文档支持与使用咨询（以授权方服务渠道为准）。
2. 以下情形不属维护范围：
   - 被授权方自行修改源码导致的问题；
   - 服务器环境、第三方软件（操作系统、数据库、依赖组件）引发的问题；
   - 不可抗力或网络/机房故障导致的问题。

## 七、数据与隐私

1. 被授权方对其在系统中录入、产生的全部数据拥有所有权；
2. 授权方在提供服务过程中接触被授权方数据时，应尽保密义务，不得用于本协议之外的用途；
3. 本系统部署于被授权方自有或指定服务器，授权方不承担数据日常备份义务（系统内置备份功能供被授权方使用）。

## 八、免责与责任限制

1. 本系统按"现状"提供，授权方不对系统的适销性、特定用途适用性作任何明示或默示担保；
2. 因使用或无法使用本系统造成的任何间接、附带、特殊或后果性损失（包括数据丢失、利润损失），授权方不承担责任；
3. 授权方对因本协议产生的累计赔偿责任，不超过被授权方实际支付的授权费用总额。

## 九、违约处理

1. 被授权方违反本协议第五条的，授权方有权立即终止本协议、收回授权并追究法律责任；
2. 协议终止后，被授权方应停止使用本系统并删除相关副本。

2. 本协议未尽事宜，双方另行书面协商；
3. 本协议自授权码激活或被授权方实际使用本系统之日起生效。

## 十一、标准销售流程（首次 30 天试用）

为便于客户评估，授权方按以下标准流程提供首次试用：

1. **首次试用**：新合作客户可申请 **30 天试用授权**（试用版 trial），试用期内可体验系统全部功能；
2. **授权码签发**：试用授权码由授权方签发（`--edition trial --exp 30d`），绑定客户站点域名；
3. **到期处理**：试用到期后系统自动判定为过期状态，后台顶部显示提醒横幅，功能不受影响，等待客户续期；
4. **转正式**：客户决定采购后，授权方签发正式版授权码（专业版/旗舰版），客户在后台重新激活即可延续使用，无需重装系统；
5. **数据保留**：试用期内产生的数据在授权到期后仍保留，正式激活后继续可用。
